# ST47 — A terminal and live list used together

**Priority:** 🟰 Medium · **State:** Backlog

**What a user gains.** A person can use the embedded terminal like an ordinary terminal and keep task list --watch open beside it.

**The test.** Use the embedded terminal as an ordinary terminal and open task list --watch beside it. States and the clearance hint update. Input reaches the task whole and unchanged; Ctrl-C restores the terminal.
