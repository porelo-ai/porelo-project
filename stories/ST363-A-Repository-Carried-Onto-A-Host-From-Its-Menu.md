# ST363 — A repository carried onto a host from its menu

**Priority:** 🟰 Medium · **State:** Backlog

**What a user gains.** A person who sees a repository on a machine's project page moves it onto that machine, or off it, from the repository's own menu, without going to the machine page first.

**The test.** On a rented host's project page, open a not-carried repository's menu and carry it onto the host: it is carried there and its row says so. Open the same repository's menu again and take it off: it is gone from the host and its row says so.
