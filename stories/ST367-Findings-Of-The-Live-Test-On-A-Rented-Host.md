# ST367 — Findings of the live test on a rented host

**Priority:** 🔼 High · **State:** Backlog

**What a user gains.** A person who rents a host, hands it their token, signs an agent in and runs planned work there sees each step progress in the window, can approve the pull request a task opens, and gets work done on the host's newest copy, without false refusals or raw error and event lines.

**The test.** On a rented host carrying part of a project: no refusal for a repository not carried; a sign-in refusal says agent and machine; sign-in and board starts show progress and open the task; a planned tile names issue, story, stage; no raw event lines; the person approves an unattended task's pull request; a task started after a planner save works on it; central state is a chip.
