# ST356 — A task that reads everything hands back its result and ends as chosen

**Priority:** 🟰 Medium · **State:** Backlog

**What a user gains.** A task started with a result file hands that file back at its end, up to 1 MiB, and the window reads it; at the start the person can choose that the task ends with its agent or stops when they leave its shell; a read-all task sees every repository, writes none and leaves nothing behind; the idea walk says at the builder's own step when a builder ended unfinished and why.

**The test.** Start a task with a result file and end it: the window shows the file; start with each end choice: the task ends or stops as chosen; on the rented host a read-all start sees every repository, writes none and leaves nothing; a builder out of time is named at its own step.
