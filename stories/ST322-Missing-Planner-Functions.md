# ST322 — Missing planner functions

**Priority:** 🔼 High · **State:** Accepted

**What a user gains.** The planning board does what a person reaches for: the search finds an issue and shows its story, a story's priority is changed on the board, and a disabled action names the run that holds it and leads there.

**The test.** Search for an issue's number: its story shows with the issue marked, scrolled into view. Change a story's priority on its page and from its card: the board re-sorts and the change is saved. Open a story's menu while a run needs attention: the disabled Start work names that run and opens it.
