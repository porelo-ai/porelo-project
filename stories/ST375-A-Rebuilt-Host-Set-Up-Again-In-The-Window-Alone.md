# ST375 — A rebuilt host set up again in the window alone

**Priority:** 🔼 High · **State:** Backlog

**What a user gains.** A person whose rented host was rebuilt or rented again under the same name sets it up again in the window alone, is told plainly when files of an earlier setup are in the way, and sees how far handing on the token has come.

**The test.** A host already set up once is rebuilt with a new host key under the same name and address. Setting it up again runs through after the person accepts the new key, without removing files by hand; the token step never says the machine could not be reached while it answers. Putting a project on it shows each step of the token's hand-over and the time it has run, and ends in Done.
