# ST375 — A rebuilt host set up again in the window alone

**Priority:** 🔼 High · **State:** Backlog

**What a user gains.** A person whose rented host was rebuilt or rented again under the same name sets it up again in the window alone, is told plainly when files of an earlier setup are in the way, and sees how far handing on the token has come.

**The test.** A host set up once is rebuilt under the same name with a new key. Setting it up again runs through after the key is accepted, with no files removed by hand and no 'could not be reached' while it answers; a removed machine leaves no SSH files. Putting a project on it shows each step of the token's hand-over and its time, and ends in Done.
