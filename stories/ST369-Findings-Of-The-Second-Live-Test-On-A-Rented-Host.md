# ST369 — Findings of the second live test on a rented host

**Priority:** 🔼 High · **State:** Backlog

**What a user gains.** A person who sets up a rented host and puts a project on it gives the host their forge token only where the window cannot hand it on by itself, and meets no other step of the second live test that stops, repeats or misleads them.

**The test.** On a rented host: set the host up with the token from this computer's Porelo-Vault, then put a project on it; the window hands the token on for the project's repositories without asking a second time. Each further finding of the second live test is shown fixed on a rented host.
