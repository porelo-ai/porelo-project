# Release plans

Each release has its own folder here, planned in `<release>/plan.yml`: its sprints, the functions the operator tests at
the end of each, and the issues each function needs. `plan/after.yml` holds the order between them.

**The pages are on the branch [`plan-pages`](https://github.com/porelo-ai/porelo-project/tree/plan-pages/plan).** A
workflow renders them from every repository's `main` at a push here and about hourly. `pages-index.md` is the top of
that branch's first page.
